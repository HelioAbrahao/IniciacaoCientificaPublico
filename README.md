# Iniciação Científica

Neste repositório reúno os códigos, textos e explicações que estou desenvolvendo durante minha iniciação científica.

O projeto estuda como diferentes estratégias de poda afetam o desempenho de algoritmos de backtracking conforme aumenta a complexidade dos problemas. A ideia é comparar implementações com e sem poda, observando o tempo de execução e a quantidade de estados visitados.

Também vou registrar aqui meus estudos e explicações sobre os assuntos do projeto. As implementações são feitas em C++.
